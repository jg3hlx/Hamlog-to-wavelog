## Turbo HAMLOGのQSLカード印刷機能を使い [wavelog](https://github.com/wavelog/wavelog) に取り込む為ためのADIFファイルを作成する方法

## 使用上の注意点

* HAMLOGの出力制限のため、一度に30000件以上の出力ができません。レコード番号で分割して出力してください。
* ADIFファイルはC:\Hamlog\wavelogに出力するようにサンプルは設定されています。
* ログに日本語が含まれている場合、出力されたADIFファイルの文字コードを"UTF-8"に変更してください。
* 事前にADIFエクスポートを行うことを推奨します。
 
## サンプル

 * 基本例　Hamlog to wavelog 1.qsl
 
 * QSLカードの受領情報例　Hamlog to wavelog 2.qsl

   #### ※QSLカードの受領情報についてはHAMLOGでの管理方法に合わせて変更してください。

## 出力されたADIFファイルに漢字が含まれる場合

１．出力したADIFファイルをメモ帳で開く。

２．メニューの「ファイル」＞「名前を付けて保存」をクリック。

３．保存ダイアログの下部にある「エンコード」の項目から「UTF-8」を選択。

４．「保存」ボタンをクリックして上書き（または別名で）保存する。



## wavelogへの取り込み

１．画面右側に表示されているコールサインをクリックする。

２．表示されたメニュー内の「ADIF インポート/エクスポート」をクリックする。

３．①取り込むステーション（ログファイル）を選択する。

４．②取り込みたいADIFファイルを選択する。

５．③アップロードをクリックして取り込みを開始する。
